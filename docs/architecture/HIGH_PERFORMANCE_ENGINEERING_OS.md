## 2. La Distinción Fundamental de la NASA
* **Verification**: ¿Construimos el sistema correctamente de acuerdo a la especificación técnica? (Tests unitarios, análisis causal, invariantes).
* **Validation**: ¿Construimos el sistema correcto para resolver la necesidad real del usuario? (Pruebas de aceptación, métricas de resultado, feedback de producto).
