# El Canon de los 20 Libros Legendarios y la Ruta de Maestría en Software

> **Axioma del Arquitecto Senior:**  
> **"SENIORITY != KNOWING MORE FRAMEWORKS. SENIORITY = MAKING BETTER DECISIONS UNDER CONSTRAINTS"**.  
> Este compendio contiene las 20 obras más influyentes de la historia de la computación y la ruta formativa de 5 etapas para dominar la ingeniería de software desde primeros principios.

---

## 1. La Ruta Legendaria de Maestría (The 5-Stage Path)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    LA RUTA FORMATIVA DEL INGENIERO DE ÉLITE                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [ETAPA 1] MADUREZ PROFESIONAL Y HÁBITOS                                    │
│      📖 The Pragmatic Programmer (Hunt & Thomas)                            │
│      • Ortogonalidad, trazabilidad, Broken Windows y mentalidad proactiva.  │
│                                                                             │
│  [ETAPA 2] DESMITIFICACIÓN DEL HARDWARE                                     │
│      📖 Computer Systems: A Programmer's Perspective (Bryant & O'Hallaron)  │
│      • Jerarquía de memoria, caches L1-L3, ensamblador y memoria virtual.   │
│                                                                             │
│  [ETAPA 3] RIGOR ALGORÍTMICO Y COMPLEJIDAD                                  │
│      📖 Introduction to Algorithms - CLRS (Cormen et al.)                   │
│      • Análisis asintótico ($\mathcal{O}$), grafos, programación dinámica.  │
│                                                                             │
│  [ETAPA 4] ARQUITECTURA Y SISTEMAS DEL MUNDO REAL                           │
│      📖 Designing Data-Intensive Applications (Kleppmann)                   │
│      📖 Refactoring (Fowler) + Domain-Driven Design (Evans)                 │
│      • Sistemas distribuidos, consenso, refactorización segura y DDD.       │
│                                                                             │
│  [ETAPA 5] MAESTRÍA FORMAL, COMPILADORES Y COMPUTACIÓN TEÓRICA              │
│      📖 The Art of Computer Programming (Knuth)                             │
│      📖 SICP (Abelson & Sussman) + Dragon Book (Aho et al.)                 │
│      • Abstracción matemática pura, AST, parsers y compilación interna.     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. Los 10 Libros de Máxima Prioridad y su Impacto en EOS

| # | Obra Maestra | Autor | Por Qué es Vital en EOS |
| :--- | :--- | :--- | :--- |
| **1** | **Designing Data-Intensive Applications** | Martin Kleppmann | Gobierna la persistencia inmutable, replicación y consenso de misiones. |
| **2** | **Computer Systems: A Programmer’s Perspective** | Bryant & O’Hallaron | Guía el control de memoria heap, latencia p99 y bajo overhead del runtime. |
| **3** | **Introduction to Algorithms (CLRS)** | Cormen et al. | Resuelve la topología de dependencias DAG en ondas de ejecución atómicas. |
| **4** | **The Pragmatic Programmer** | Hunt & Thomas | Establece la responsabilidad técnica y el principio DRY en todo el código. |
| **5** | **Refactoring** | Martin Fowler | Fundamento de la fase REFACTOR en el nano-ciclo de Uncle Bob. |
| **6** | **Working Effectively with Legacy Code** | Michael Feathers | Base de las pruebas de caracterización y costuras en proyectos heredados. |
| **7** | **Design Patterns** | Gamma, Helm, Johnson, Vlissides | Provee el vocabulario unificado de diseño y patrones GoF. |
| **8** | **Structure and Interpretation of Computer Programs** | Abelson & Sussman | Modelo mental para la manipulación de grafos AST y evaluadores simbólicos. |
| **9** | **Domain-Driven Design (DDD)** | Eric Evans | Define los límites estrictos de contexto (`Bounded Contexts`) de EOS. |
| **10**| **The Art of Computer Programming** | Donald E. Knuth | El estándar máximo de rigor matemático y análisis paso a paso. |
