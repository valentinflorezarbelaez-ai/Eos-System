# Directorio oficial de GitHub para EOS

**Fecha de investigación:** 21 de agosto de 2026.  
**Origen:** investigación externa (notas verificadas + directorio completo).  
**Ruta canónica en este workspace:** `docs/intelligence/directories/AI_OFFICIAL_GITHUB_DIRECTORY_ES.md`

Este directorio reúne organizaciones oficiales, laboratorios y ecosistemas tecnológicos de alta relevancia para investigar inteligencia artificial, desarrollo agentico, infraestructura, modelos, herramientas de desarrollo y operación de software.

> **Criterio de oficialidad:** una organización se considera oficial cuando su página de GitHub pertenece a la empresa o laboratorio y muestra verificación o enlace al dominio corporativo. Un repositorio se incluye como repositorio público destacado de esa organización; su existencia no implica que sea un producto comercial soportado, estable, seguro para producción o permanentemente mantenido.

## 8. Reglas de uso

Revisar licencia, mantenimiento, dependencias, ataque, compatibilidad, procedencia y pruebas **antes** de instalar. Decisión por repo: `ADOPT` | `ADAPT` | `INSPIRE` | `DEFER` | `REJECT`.
