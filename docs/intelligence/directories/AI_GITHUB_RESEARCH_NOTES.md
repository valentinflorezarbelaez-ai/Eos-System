## Method note

A GitHub organization URL is treated as official only when it is the company/lab organization itself and/or its page links to the official corporate domain. Individual repositories are listed as official-public candidates; repository activity and purpose should be checked on their own pages before making stronger claims.

GitHub organization names are case-insensitive in URLs, but the canonical display URL may use capitalization. Repository status can change; labels are as of the research date only.
