- **Design Mode** (date unknown)
  https://cursor.com/docs/agent/design-mode
  Design Mode lets you direct agents with visual prompts. Ways to direct the agent — Design Mode gives you several ways to convey intent. Select an element — Click any element in the running product to target it. Select multiple elements — Multi-select helps when the change depends on a relationship between elements. Draw on the page — Drawing tells the agent which area of the page your instruction applies to. Narrate by voice — You can narrate instructions with your voice instead of typing. What the agent sees — Picking an element adds two complementary signals to context: Element identity : the xpath, the component, attributes, computed styles, and props from the fiber tree. Work in flow — When you refine an interface, one edit usually leads to the next.
