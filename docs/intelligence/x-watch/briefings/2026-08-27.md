## New official items
- **Available models** (date unknown)
  https://cursor.com/help/models-and-usage/available-models
  Cursor supports a range of AI models from multiple providers. Which models are available? — Cursor offers its own models (Grok 4.5 and Composer) in the Cursor Models pool alongside other frontier models from OpenAI, Anthropic, and Google. Which model should I use? — Auto selects models that balance intelligence, cost, and reliability. Which models does Cursor Router route across? — Cursor Router routes across these models: GPT-5.5 Claude Opus 5 Grok 4.5 Claude Fable 5 Required: Grok 4.5. Can I see which model Cursor Router used for my request? — By default, the routed model identity is hidden so you judge results on merit. How much does Auto cost? — All Auto modes bill at the list price of the model each request is routed to. How much does Grok 4.5 cost? — Grok 4.5 has two speeds, each with its own token rates: Standard : $2.00 per 1M input tokens, $6.00 per 1M output tokens, $0.50 per 1M cache read tokens Fast : $4.00 per 1M input tokens, $18.00 per 1M output tokens, $1.0 How much do models cost? — Each model has its own per-token rate set by the provider (OpenAI, Anthropic, Google, etc.). What model am I talking to? — The active model is shown in the model picker at the top of the chat panel. What models do subagents use? — Built-in subagents (Explore, Bash, Browser) select their model automatically based on the subtask. What does "model not available" mean? — Some models may not be available in certain regions based on restrictions set by the model providers (not Cursor).
