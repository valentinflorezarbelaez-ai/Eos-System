  Agent can control a web browser to test applications, audit accessibility, convert designs into code, and more. Native integration — Agent displays browser actions like screenshots and actions in the chat, as well as the browser window itself either in a separate window or an inline pane. Browser capabilities — Agent has access to the following browser tools: Navigate — Visit URLs and browse web pages. Click — Interact with buttons, links, and form elements. Type — Enter text into input fields and forms. Scroll — Navigate through long pages and content. Screenshot — Capture visual representations of web pages. Console Output — Read browser console messages, errors, and logs. Network Traffic — Monitor HTTP requests and responses made by the page. Session persistence — Browser state persists between Agent sessions based on your workspace. Use cases Security — Browser runs as a secure web view and is controlled using an MCP server running as an extension. Authentication and isolation — The browser implements several security measures: Token authentication : Agent layout generates a random authentication token before each browser session starts Tab isolation : Each browser tab receives a unique random I Tool approval — Browser tools require your approval by default. Allow and block lists — Browser tools integrate with Cursor's security guardrails. Browser context — The browser opens as a pane within Cursor, giving Agent full control through MCP tools.
