## 2024-05-24 - File IO Bottlenecks\n**Learning:** In a codebase heavily reliant on `fs.existsSync` inside synchronous or loop contexts, we can experience significant main thread blocking due to Node.js IO constraints.\n**Action:** Use try/catch with async operations or minimize file system checks whenever possible. Always replace `fs.existsSync` prior to use with try/catch to avoid TOCTOU.
