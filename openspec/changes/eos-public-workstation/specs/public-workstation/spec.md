# Spec — Public workstation page

## Requirements

### What EOS is

Given a visitor opens `site/index.html`  
When the document is read  
Then it describes EOS as Valentin Florez's governed engineering operating system  
And it states that specifications, tests, and human approval are required gates  
And it does not claim a Google-scale monorepo or Spanner  
And it does not claim the product is superior to Devin, Cursor, or any other named agent.

### Who it is for

Given the same document  
When the audience section is read  
Then it addresses operators who want a governed workspace any IDE or agent can drive  
And it names Valentin's operating system without inventing client metrics.

### Works with

Given the works-with section  
When the driver list is read  
Then it names Cursor, Windsurf, Google Antigravity, Zed, Trae, PearAI, AWS Kiro, Claude Code, Aider, Manus, and Replit Agent  
And each name has an original text or geometric mark in the page itself  
And the repository contains no third-party trademark logo file for those products  
And the footer states that those names are trademarks of their owners and that EOS is not affiliated with them.

### Honesty

Given the page  
When status language is read  
Then autonomy is described as supervised (`LEVEL_2`)  
And `PRODUCTION_READY` is not claimed as true  
And no numeric performance, user, or uptime metric is presented as measured.

### Out of page

Given the homepage HTML  
When it is searched  
Then it does not mention Performance Talent Group, roster athletes, or the PTG Instagram pipeline.

### Access

Given the page markup  
When it is checked  
Then it has `lang`, one `h1`, a skip link, a main landmark, and text alternatives or accessible names for marks  
And motion is disabled under `prefers-reduced-motion: reduce`.
