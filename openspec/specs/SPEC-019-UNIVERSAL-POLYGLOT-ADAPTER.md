# OPENSPEC BASE SPECIFICATION: UNIVERSAL POLYGLOT REPOSITORY ADAPTER (SPEC-019)

## 1. Scope
Governs deep architectural inspection, polyglot stack fingerprinting (TypeScript, Go, Rust, Python, Flutter, C/C++, Java), multi-language static analysis, and automated Golden Path synthesis across any software project of any class or complexity.

## 2. Requirements (EARS)
- **UBIQUITOUS**: THE SYSTEM SHALL fingerprint project archetype, language, package manager, test framework, and containerization setup across 20+ software stacks with zero external runtime dependencies (`dependencies: {}`).
- **EVENT-DRIVEN**: WHEN any local or remote repository is audited, THE SYSTEM SHALL evaluate five core architectural pillars (Layer Purity, Test Infrastructure, Secret Security, CI/CD Gateways, and AI Context Scaffolding), outputting an Architectural Health Index (0-100) and an immutable SHA-256 Merkle receipt.
- **ERROR-DRIVEN**: IF the analyzed project lacks standardized Golden Path descriptors, THEN THE SYSTEM SHALL synthesize stack-tailored Backstage RFC-42 descriptors (`catalog-info.yaml`), GitHub Actions CI workflows (`.github/workflows/ci.yml`), pre-commit secret scanners, and agent context files (`AGENTS.md`/`CLAUDE.md`).
- **STATE-DRIVEN**: WHILE evaluating codebases in dry-run mode, THE SYSTEM SHALL guarantee zero external write mutations, returning detailed diagnostic telemetry and remediation plans.
- **UBIQUITOUS (Identity Determinism)**: THE SYSTEM SHALL derive the repository identity from the manifests themselves in strict priority order (`catalog-info.yaml` `metadata.name` → `package.json` `name` → `go.mod` module final segment → `Cargo.toml` `[package].name` → `pyproject.toml` `[project].name`/`[tool.poetry].name` → `pubspec.yaml` `name` → `pom.xml`/`build.gradle`), falling back to the checkout directory name only when no manifest declares an identity, so audit receipts remain reproducible across CI runners, ephemeral sandboxes and local clones.
- **UBIQUITOUS (Primary Language by Mass)**: THE SYSTEM SHALL rank detected languages by weighted source mass (build manifests seed a baseline weight, source files add one unit each) with a deterministic tie-breaker, ensuring the reported primary language reflects the codebase and never the arbitrary order in which manifests were probed.
- **UBIQUITOUS (Path Anchoring)**: THE SYSTEM SHALL enumerate only the source-controlled surface of a Git work tree (`git ls-files --cached --others --exclude-standard`), so git-ignored local tool state, secrets and build caches are never fingerprinted or secret-scanned; paths SHALL be emitted relative to the audited repository root (never to the process working directory), sorted for deterministic receipts, and SHALL count regular source files only, so nested artifacts (e.g. `deploy/Dockerfile`) are detected and `totalSourceFiles` is not inflated by directory entries.
- **UBIQUITOUS (Shift-Left Toolchain)**: THE SYSTEM SHALL detect the enforced static-analysis and formatting toolchain (`eslint`, `biome`, `prettier`, `golangci-lint`, `ruff`, `flake8`, `pylint`, `rubocop`, `clang-format`, `checkstyle`, `editorconfig`) from config files, manifest-declared dev dependencies and language-native defaults (`gofmt`, `rustfmt`, `dart_analyze`), reporting `none` only when no toolchain is declared.
